## 📌 About the Project

HemoCare is a free, offline Blood Bank Management
System developed using Python, Flask, and SQLite.

It helps manage blood donors, donations, blood
components, inventory, and hospital records through
a centralized application.

## ✨ Key Features

- 👥 Donor registration and management
- 🩸 Blood donation and inventory tracking
- 🧪 Serology record management
- 🏥 Hospital records
- 🚨 Low-stock alerts
- ⏳ Blood unit expiry monitoring
- 🔐 Secure login
- 📊 Excel and PDF report generation
- 💻 Offline functionality

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- pip

### Installation

1. Clone this repository.

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

   ```bash
   cd HemoCare
   ```

3. Install dependencies listed in your project's
   requirements file.

4. Run the application using its actual entry point.

   ```bash
   python app.py
   ```

> Make sure the repository URL and dependencies
> match your actual project configuration.
